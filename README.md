# 🤖 Telegram Bot для Кофейни/Магазина с Доставкой

Полнофункциональный Telegram бот для кофеен, магазинов и забегаловок с системой доставки и самовывоза.

## 📋 Возможности

### Для клиентов:
- **Регистрация** через Telegram аккаунт (автоматически)
- **Интерактивное меню** с категориями товаров
- **Корзина** с управлением количеством товаров через inline кнопки (➖/➕)
- **Выбор типа получения**: самовывоз или доставка
- **Отслеживание статуса заказа** в реальном времени
- **История заказов** с деталями
- **Профиль пользователя** с контактами и адресом
- **Загрузка фото/видео** товаров

### Для администраторов:
- **Защищённая админ-панель** в Telegram
- **Управление заказами**: подтверждение, изменение статуса, отмена
- **Управление товарами**: добавление, редактирование, удаление
- **Загрузка изображений и видео** для товаров через API
- **Управление категориями**
- **Зоны доставки** с настройкой стоимости
- **Статистика** по заказам и выручке

## ⚙️ Установка

1. **Перейдите в директорию проекта:**
```bash
cd /workspace
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
```

4. **Отредактируйте `.env`:**
```env
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_USERNAME=your_telegram_username
DATABASE_URL=sqlite+aiosqlite:///./coffee_shop.db
MEDIA_ROOT=/workspace/static/media
```

## 🚀 Запуск

### Запуск Telegram бота:
```bash
python -m app.bot
```

### Запуск API сервера (для загрузки товаров через админку):
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 🎯 UX решения в боте

### Выбор количества товаров:
1. Пользователь выбирает товар из категории
2. Открывается карточка товара с кнопками:
   - ➖ уменьшить количество
   - ➕ увеличить количество
   - 🛒 В корзину (с указанием общей суммы)
3. Количество отображается inline в кнопке

### Оформление заказа:
1. Просмотр корзины со списком товаров
2. Выбор типа: Самовывоз 🏠 или Доставка 🚚
3. Для доставки - запрос адреса
4. Поделиться контактом через кнопку Telegram
5. Подтверждение заказа с итоговой суммой

### Статусы заказов:
- ⏳ Ожидает подтверждения
- ✅ Подтвержден
- 👨‍🍳 Готовится
- 🎉 Готов к выдаче
- 🚚 Доставляется
- ⭐ Завершен
- ❌ Отменен

### Админ-панель:
1. Поток статусов: нельзя перейти из "Ожидает" сразу в "Готов"
2. Автоматические уведомления клиентам при изменении статуса
3. Быстрый доступ к последним 20 заказам
4. Детальная информация о заказе с контактами клиента

## 🔐 Администрирование

### Настройка админа:
1. В `.env` укажите ваш username без `@`:
```env
ADMIN_USERNAME=your_username
```

2. Или установите флаг `is_admin=True` в базе данных напрямую

### Доступ к админ-панели:
1. Отправьте команду `/admin` в боте
2. Если вы авторизованы - откроется панель управления

### Функции админ-панели:
- 📊 **Статистика** - общие показатели по заказам
- 📦 **Заказы** - управление всеми заказами
- ☕ **Товары** - CRUD операции через API
- 📂 **Категории** - управление категориями
- 🚚 **Зоны доставки** - настройка стоимости доставки

## 📊 API Endpoints (для админки)

### Категории:
- `GET /api/categories` - список категорий
- `POST /api/categories` - создать категорию
- `DELETE /api/categories/{id}` - удалить категорию

### Товары:
- `GET /api/products` - список товаров
- `GET /api/products?category_id=1` - товары категории
- `POST /api/products` - создать товар (multipart/form-data)
  - `name` - название
  - `description` - описание
  - `price` - цена
  - `category_id` - ID категории
  - `image` - файл изображения (опционально)
  - `video` - файл видео (опционально)
- `PUT /api/products/{id}` - обновить товар
- `DELETE /api/products/{id}` - удалить товар

### Заказы:
- `GET /api/orders` - список заказов
- `GET /api/orders/{id}` - детали заказа
- `PUT /api/orders/{id}` - обновить статус

### Зоны доставки:
- `GET /api/delivery-zones` - список зон
- `POST /api/delivery-zones` - создать зону
- `DELETE /api/delivery-zones/{id}` - удалить зону

## 🏆 Принципы разработки

### SOLID:
1. **Single Responsibility Principle (SRP)**:
   - `handlers/` - только обработка сообщений
   - `services/` - только бизнес-логика
   - `keyboards/` - только создание клавиатур
   - `models/` - только модели данных

2. **Open/Closed Principle**:
   - Легко добавить новые команды через регистрацию хендлеров
   - Расширяемая система статусов заказов

3. **Liskov Substitution Principle**:
   - Все сервисы имеют единый интерфейс

4. **Interface Segregation Principle**:
   - Раздельные схемы для создания/обновления/ответа

5. **Dependency Inversion Principle**:
   - Зависимость от абстракций (AsyncSession), а не реализаций

### Дополнительные практики:
- **Асинхронность** - все I/O операции асинхронные
- **Валидация данных** - Pydantic схемы
- **Типизация** - type hints везде где возможно
- **Масштабируемость** - легкая замена SQLite на PostgreSQL

## 📝 Пример добавления товара через API

```bash
curl -X POST "http://localhost:8000/api/products" \
  -F "name=Капучино" \
  -F "description=Классический капучино" \
  -F "price=250.0" \
  -F "category_id=1" \
  -F "image=@cappuccino.jpg"
```

## 🔧 Настройка базы данных

По умолчанию используется SQLite. Для PostgreSQL:

1. Установите драйвер:
```bash
pip install asyncpg
```

2. Измените в `.env`:
```env
DATABASE_URL=postgresql+asyncpg://user:password@localhost/coffee_shop
```
